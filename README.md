# Git workflow demo

这是一个用于练习 Git 工作流的演示仓库，现在扩展成了一个基础 TypeScript 前端项目结构。

## Project structure

```text
git-workflow-demo
├─ index.html
├─ package.json
├─ tsconfig.json
├─ README.md
└─ src
   └─ main.ts
```

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Git workflow
Local commits are pushed to GitHub with git push.
